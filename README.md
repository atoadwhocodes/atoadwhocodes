# 🐸 aToadWhoCodes Creative

**Independent software development · Retro game engineering · Digital preservation**

Welcome to **The Pond**. aToadWhoCodes Creative explores classic computing and game hardware through modern software development, preservation tools, and technical experimentation.

## Featured public projects

### 🎮 [ATWC-1 Custom NES Mapper](https://github.com/atoadwhocodes/ATWC_Nes_Mapper)
An experimental NES mapper architecture exploring flexible PRG/CHR banking, advanced graphics capabilities, emulator integration, and hardware-oriented testing. Follow the repository for mapper specifications, test ROMs, and implementation progress.

### 💾 [DiskScribe](https://github.com/atoadwhocodes/Diskscribe2026)
Software tools for disk images, legacy data formats, extraction, and digital preservation workflows.

### 🕹️ [NES JRPG Proof of Concept](https://github.com/atoadwhocodes/nes-jrpg-proof-of-concept)
Research and prototyping for a retro role-playing game engine on the Nintendo Entertainment System.

### 🐸 [Hello Frog](https://github.com/atoadwhocodes/Hello_Frog)
Experiments and learning projects in retro-oriented development.

## Other ongoing work

- **PondScribe:** OCR, document conversion, language translation, and local-assisted processing.
- **Retro game ports and engines:** 6502 assembly, console-specific graphics, custom mapper support, and RPG systems.
- **Preservation research:** archival workflows, legacy disk and game formats, and reproducible tooling.
- **Compression research:** experimental storage and lossless data-processing concepts.

Some work is private or in prototype stages; public repositories show what is currently available to inspect.
